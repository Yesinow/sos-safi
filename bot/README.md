# 🔥 رادار البوز المغربي

بوت كيجمع أخبار المغرب من عشرات المصادر، كيرتّبها حسب **احتمال التفاعل الحقيقي**،
وكيصيفط ليك غير الأخبار المرشحة للفيرال (تيليغرام، ntfy، ديسكورد ولا واتساب): **عنوان + فقرة قصيرة + صورة + رابط**.

كيسالي الدورة كاملة ف**أقل من 5 ثواني** (السقف المضبوط هو 7 دقائق، ما كيتقربش ليه).

---

## 1. تشغيل سريع

```bash
cd bot
node src/index.js                 # تقرير فالطرفية + HTML + Markdown
node src/index.js --dry-run       # وريّ شنو غادي يتصيفط، بلا إرسال
node src/index.js --category sport
node src/index.js --help
```

ما كاين حتى تبعية (`npm install` ماشي ضروري) — غير Node 18 أو أحدث.

المخرجات كتمشي ل`bot/out/` :

| الملف | الفايدة |
|---|---|
| `buzz.html` | لوحة عربية فيها زر نسخ لكل منشور — حلّها فالمتصفح |
| `buzz.md` | نفس التقرير بصيغة نصية |
| `buzz.json` | البيانات الخام (النقط، الإشارات، المصادر) |

---

## 2. كيفاش كتّحسب نقطة البوز (من 100)

ماشي تخمين — ستة إشارات قابلة للقياس، الأوزان كاملة فـ`config.json`:

| الإشارة | الوزن | شنو كتقيس |
|---|---|---|
| `trend` | 30 | التطابق مع **Google Trends المغرب** — شنو كيقلبو عليه المغاربة دابا فعلاً، بحجم البحث |
| `spread` | 25 | شحال من موقع **مختلف** نشر نفس الخبر (أقوى مؤشر على الانتشار) |
| `velocity` | 18 | سرعة النشر: مقالات/ساعة منذ أول نشرة |
| `emotion` | 15 | كلمات كتثير التفاعل (عاجل، فيديو، فضيحة، احتجاج…) ناقص الصيغ الإدارية الباردة |
| `freshness` | 12 | نصف العمر 5 سوايع — الخبر البايت كيطيح |
| `pageFit` | 10 | تشابه مع مواضيع **نجحات قبل فصفحتك** (يلا ربطتي فايسبوك) |

بعدها: ضرب فمعامل الفئة (`categoryBoost`)، وضرب ×0.25 إلا سبق وتصيفط ليك موضوع مشابه.

**الأخبار كتّجمّع فمواضيع أولاً**: 739 خبر ولّاو 340 موضوع متمايز. يعني "56 موقع نشرو نفس الخبر"
كيتحسب بعد ما البوت يعرف بلي هاد 56 مقال كيهضرو على نفس القضية.

---

## 3. بوابة الفيرال — قلب الموضوع

ما كيتصيفط ليك **حتى شي خبر** إلا إلا دار البوابة كاملة (`config.json ← viralGate`):

```json
{
  "minScore": 80,           // نقطة البوز — عالية بقصد
  "minSources": 3,          // 3 مواقع مختلفة على الأقل
  "maxAgeHours": 3,         // آخر نشرة ما تفوتش 3 سوايع
  "maxStoryAgeHours": 6,    // أغلب التغطية خاصها تكون ديال آخر 6 سوايع
  "rejectRedirectLinks": true,
  "maxPerRun": 5
}
```

**`maxStoryAgeHours` كيقيس العمر الوسيط ديال التغطية**، ماشي أقدم مقال. خبر فيه 40 مقال من 43
تنشرو فآخر ساعتين هو خبر خارج دابا، حتى لو كان شي مقال تمهيدي ديال البارح.

### 🎯 شنو كتعني عتبة 80

| العتبة | شنو غادي توصلك |
|---|---|
| **80+** (افتراضي) | غير الأخبار الكبيرة: تغطية واسعة + رائج فGoogle + طازج. **1 لـ4 فاليوم** فأيام الأخبار القوية، و**صفر** فالأيام الهادئة |
| 70 | ~5-10 فاليوم |
| 60 | ~15-25 فاليوم |

جرّبت: خبر بـ43 موقع، لو كان طازج كيوصل **87/100**. يعني 80 قابلة للبلوغ، ولكن للأخبار الكبيرة بوحدها.
إلا شفتي بلي ساكت بزاف: `--gate-score 70`.

`--all` كيتجاوز البوابة · `--fresh 2` كيشدّ الطزاجة · `--gate-score N` كيبدّل العتبة.

## 4. وين توصلك الأخبار

اختار قناة بـ`BUZZ_CHANNEL` (ولا `--channel`). مرتّبين من الأبسط:

| القناة | الإعداد | صور | التكلفة |
|---|---|---|---|
| **`telegram`** ✅ موصى بها | بوت من `@BotFather` ف**دقيقة وحدة** | ✅ مرفق حقيقي | مجاني بلا حدود |
| `ntfy` | **بلا حساب أصلاً** — غير سمّي موضوع وحمّل التطبيق | ✅ مرفق | مجاني |
| `discord` | نسخ رابط Webhook من إعدادات القناة | ✅ | مجاني |
| `whatsapp` | شوف القسم 4-ب | ✅ | حسب المزوّد |
| `console` | بلا إرسال — كلشي فالطرفية | — | — |

### أ. تيليغرام (الأسهل والأفضل)

1. حل تيليغرام وصيفط `/newbot` لـ**@BotFather**.
2. سمّي البوت ← كيعطيك **التوكن** (بحال `8123456:AAH...`).
3. صيفط أي رسالة للبوت ديالك، من بعد حل:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   وخود `chat.id` — هادا هو `TELEGRAM_CHAT_ID`.
4. الأسرار: `TELEGRAM_TOKEN` و`TELEGRAM_CHAT_ID` و`BUZZ_CHANNEL=telegram`.

```bash
TELEGRAM_TOKEN=... TELEGRAM_CHAT_ID=... node src/index.js --send --channel telegram
```

### ب. ntfy (بلا حساب نهائيًا)

1. حمّل تطبيق **ntfy** (Android / iOS).
2. اختار اسم موضوع صعب التخمين، مثلاً `buzz-maroc-k7f2p9`.
3. اشترك فيه من التطبيق.
4. السر الوحيد: `NTFY_TOPIC` + `BUZZ_CHANNEL=ntfy`.

⚠️ أي واحد عارف اسم الموضوع يقدر يقراه — لهذا خاصو يكون عشوائي.

### ج. واتساب (لي بغا)

`WA_PROVIDER` = `greenapi` (موصى به: صور + بلا نافذة 24 ساعة) · `ultramsg` · `cloud` · `callmebot`
مع  `WA_TO` = رقمك بالصيغة الدولية.

⚠️ `cloud` (Meta الرسمي) ماشي مناسب للإرسال التلقائي: خارج نافذة 24 ساعة كيفرض قوالب مؤدى عنها.

## 5. التشغيل 24/24 بلا ما تدير والو

الملف `.github/workflows/buzz-whatsapp.yml` كيشغّل البوت **كل 30 دقيقة** فGitHub Actions.
المستودع عمومي ← دقائق Actions **مجانية بلا حدود**.

### الأسرار — مهم

⚠️ **المستودع ديالك عمومي**، لهذا رقم الهاتف والمفاتيح **ما تزيدهمش فالملفات**.
زيدهم من: `Settings` ← `Secrets and variables` ← `Actions` ← `New repository secret`

| السر | القيمة |
|---|---|
|  `WA_TO` | رقم الواتساب ديالك بالصيغة الدولية، مثلاً `2126XXXXXXXX` |
| `WA_PROVIDER` | `greenapi` |
| `GREENAPI_ID` | `idInstance` ديالك |
| `GREENAPI_TOKEN` | `apiTokenInstance` ديالك |

اختياري — باش البوت يتعلّم من أداء صفحتك: `FB_PAGE_ID` و`FB_PAGE_TOKEN`.

### شروط باش الجدولة تخدم فعلاً

- ✅ **خاص الملف يكون فالفرع الرئيسي `main`.** GitHub كيشغّل `schedule` غير من الفرع الافتراضي.
  دمج هاد الفرع فـ`main` وإلا ما غادي يخدم حتى شي دورة مجدولة.
- ⏱ GitHub كيمكن ليه يأخّر الدورات المجدولة فوقت الزحام (كيتشغل فـ7 و37 من كل ساعة باش نقلّلو هاد الأثر).
- 😴 إلا بقا المستودع **60 يوم بلا حركة**، GitHub كيوقف الجدولة وكيصيفط ليك إيميل. كفاك أي commit باش ترجع.

للتجربة قبل كلشي: تبويب `Actions` ← `بوت البوز → واتساب` ← `Run workflow` ← فعّل `dry_run`.

## 6. النشر المباشر على فايسبوك (اختياري)

```bash
FB_PAGE_ID=... FB_PAGE_TOKEN=... node src/index.js --publish draft
```

`draft` كيخلق منشور غير منشور فـPublishing Tools · `schedule` كيبرمجو بعد 20 دقيقة · `live` كينشر دابا.
البوت كيولّد ليك نصّ منشور جاهز بالدارجة مع hashtags وسؤال كيحفّز التعليق.

## 7. محاذير صادقة

- **"جس نبض التفاعل فالصفحات"**: Meta ما بقاتش كتسمح بقراءة تفاعلات صفحات ماشي ديالك.
  لهذا البوت كيقيس النبض من: Google Trends (بحث حقيقي بالأرقام)، عدد المواقع اللي نقلات الخبر،
  وسرعة الانتشار — وكيتعلّم من صفحتك **نتا** إلا ربطتيها. هادو إشارات حقيقية، ماشي تقدير عشوائي.
- **تحقّق قبل النشر.** البوت كينبّهك بـ"مصدر واحد فقط" — هادوك خاصك تأكدهم بيدك.
- بعض المواقع (ChoufTV، SNRT، Medias24…) كتبلوكي الروبوهات بـCloudflare. مسجّلين كـ`optional`
  فالإعدادات، وGoogle News كيعوّضهم غالبًا.
- الترجمة ديال `news.google.com/rss/articles/...` ماشي روابط قابلة للنشر — البوت كيفضّل دايمًا
  الرابط المباشر، وإلا ما لقاش كينبّهك.
